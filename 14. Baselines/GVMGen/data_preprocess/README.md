## Data Preprocessing

Modified README for adapting the data from SNES-MVDB

### 1. Gathering the data
We'll be using the data generated by task [`12. Convert to audioset`](https://github.com/jknvlvxs/vmdb/tree/development/12.%20Convert%20to%20audioset) which is a modified version of the one established by [Audiocraft](https://github.com/facebookresearch/audiocraft/blob/main/docs/DATASETS.md).

### 2. Converting
The script `snesmvdb_to_gvmgen.py` will take the path to the data gethered from step 1 and go over each json, generating the tensor files for the videos and creating a json in the format expected by GVMGen. This is basically the equivalent of running GVMGen's `videodata_pre` and `videodata_pro` all at once over the SNES MVDB.

GVMGen's example dataset positions this data at `/dataset/music`. By default we'll be positioning it at `/dataset/snes-mvdb`.
